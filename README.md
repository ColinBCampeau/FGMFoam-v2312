# FGMFoam-v2312
FGMFoam for OpenFOAM-v2312. Modification of the FGMFoam solver provided by Michael Bertsch [1] originally implemented by Likun Ma [2]

[1] Proceedings of CFD with OpenSource Software, 2019, Edited by Nilsson H. https://dx.doi.org/10.17196/OS_CFD#YEAR_2019 

[2] L. Ma, “Computational modelling of turbulent spray combustion”, PhD, Delft University of
Technology, 2016, isbn: 978-94-6233-281-2.

Note : the solver does not solve for the mixture fraction and progress variable variances as intended in [2]
